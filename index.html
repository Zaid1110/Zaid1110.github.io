CSS Animations

CSS animations bring your website to life with smooth transitions and effects. Below are three common animations:Fade-In,Slide-In,and Bounce. Click the boxes to see them in action!

Fade-In Animation

Fades an element from invisible to fully visible.

@keyframes fadeIn {
  0% { opacity: 0; transform: scale(0.8); }
  100% { opacity: 1; transform: scale(1); }
}
.demo-box.fade {
  animation: fadeIn 1.2s cubic-bezier(0.4, 0, 0.2, 1) forwards;
}

Slide-In Animation

Slides an element from the left to its original position.

@keyframes slideIn {
  0% { transform: translateX(-100%) scale(0.8); }
  100% { transform: translateX(0) scale(1); }
}
.demo-box.slide {
  animation: slideIn 1.2s cubic-bezier(0.4, 0, 0.2, 1) forwards;
}

Bounce Animation

Creates a bouncing effect by moving the element up and down.

@keyframes bounce {
  0%, 20%, 50%, 80%, 100% { transform: translateY(0) scale(1); }
  40% { transform: translateY(-30px) scale(1.1); }
  60% { transform: translateY(-15px) scale(1.05); }
}
.demo-box.bounce {
  animation: bounce 1.2s cubic-bezier(0.68, -0.55, 0.265, 1.55) forwards;
}

JavaScript Animations

JavaScript animations use requestAnimationFramefor smooth,dynamic effects. Below are examples of smooth scrolling,opacity changes,and rotation. Click the boxes to trigger them!

Smooth Scroll

Scrolls smoothly to the Skills section using easing.

const target = document.getElementById('skills');
const start = window.scrollY;
const targetY = target.getBoundingClientRect().top + window.scrollY;
const duration = 800;
let startTime = null;

function animateScroll(time) {
  if (!startTime) startTime = time;
  const elapsed = time - startTime;
  const progress = Math.min(elapsed / duration, 1);
  const ease = t => t * (2 - t);
  window.scrollTo(0, start + (targetY - start) * ease(progress));
  if (progress < 1) requestAnimationFrame(animateScroll);
}

requestAnimationFrame(animateScroll);

Opacity Change

Fades an element out and back in.

let opacity = 1;
const duration = 1200;
let startTime = null;

function animateOpacity(time) {
  if (!startTime) startTime = time;
  const elapsed = time - startTime;
  const progress = Math.min(elapsed / duration, 1);
  const ease = t => t * t * (3 - 2 * t);
  opacity = 1 - ease(progress);
  element.style.opacity = opacity;
  if (progress < 1) {
    requestAnimationFrame(animateOpacity);
  } else {
    element.style.opacity = 1;
  }
}

requestAnimationFrame(animateOpacity);

Rotate Animation

Rotates an element 360 degrees.

let angle = 0;
const duration = 1200;
let startTime = null;

function animateRotate(time) {
  if (!startTime) startTime = time;
  const elapsed = time - startTime;
  const progress = Math.min(elapsed / duration, 1);
  const ease = t => t * t * (3 - 2 * t);
  angle = 360 * ease(progress);
  element.style.transform = `rotate(${angle}deg) scale(${1 + 0.1 * Math.sin(progress * Math.PI)})`;
  if (progress < 1) {
    requestAnimationFrame(animateRotate);
  } else {
    element.style.transform = `rotate(0deg) scale(1)`;
  }
}

requestAnimationFrame(animateRotate);

Networking Concepts

Learn key networking concepts to understand how devices communicate. Below are introductions to the OSI Model,TCP/IP,VLANs,DHCP,NAT,and OSPF.

OSI Model

The OSI (Open Systems Interconnection) model is a framework for understanding network interactions in seven layers:

  • Physical (Layer 1):Transmits raw bits over hardware (e.g.,cables,switches).
  • Data Link (Layer 2):Handles error-free transfer between nodes (e.g.,Ethernet).
  • Network (Layer 3):Manages routing and IP addressing (e.g.,IP).
  • Transport (Layer 4):Ensures reliable data transfer (e.g.,TCP,UDP).
  • Session (Layer 5):Manages sessions between applications.
  • Presentation (Layer 6):Translates data formats (e.g.,encryption).
  • Application (Layer 7):Provides network services to apps (e.g.,HTTP).

TCP/IP

TCP/IP is a set of protocols for internet communication:

  • TCP:Reliable,connection-oriented protocol ensuring data delivery.
  • UDP:Faster,connectionless protocol for low-latency tasks.
  • IP:Handles addressing and routing (e.g.,IPv4:192.168.1.1).

Example:Configuring a static IP on a Linux server:

sudo nano /etc/netplan/01-netcfg.yaml
# Add:
network:
  ethernets:
    eth0:
      addresses: [192.168.1.100/24]
      gateway4: 192.168.1.1
      nameservers:
        addresses: [8.8.8.8]
sudo netplan apply

VLANs

Virtual LANs segment a physical network into logical networks to improve security and efficiency.

Example:Configuring a VLAN on a Cisco switch:

Switch> enable
Switch# configure terminal
Switch(config)# vlan 10
Switch(config-vlan)# name SALES
Switch(config-vlan)# exit
Switch(config)# interface fa0/1
Switch(config-if)# switchport mode access
Switch(config-if)# switchport access vlan 10
Switch(config-if)# exit

DHCP (Dynamic Host Configuration Protocol)

DHCP automatically assigns IP addresses to devices on a network,reducing manual configuration.

Example:Setting up a DHCP server on Ubuntu:

sudo apt install isc-dhcp-server
sudo nano /etc/dhcp/dhcpd.conf
# Add:
subnet 192.168.1.0 netmask 255.255.255.0 {
  range 192.168.1.100 192.168.1.200;
  option routers 192.168.1.1;
  option domain-name-servers 8.8.8.8;
}
sudo systemctl restart isc-dhcp-server

NAT (Network Address Translation)

NAT allows multiple devices to share a single public IP address by translating private IP addresses to public ones.

Example:Configuring NAT on a Cisco router:

Router> enable
Router# configure terminal
Router(config)# interface GigabitEthernet0/0
Router(config-if)# ip nat inside
Router(config-if)# exit
Router(config)# interface GigabitEthernet0/1
Router(config-if)# ip nat outside
Router(config-if)# exit
Router(config)# ip nat inside source list 1 interface GigabitEthernet0/1 overload
Router(config)# access-list 1 permit 192.168.1.0 0.0.0.255

OSPF (Open Shortest Path First)

OSPF is a link-state routing protocol that uses Dijkstra's algorithm to find the shortest path in a network.

Example:Configuring OSPF on a Cisco router:

Router> enable
Router# configure terminal
Router(config)# router ospf 1
Router(config-router)# network 192.168.1.0 0.0.0.255 area 0
Router(config-router)# network 192.168.2.0 0.0.0.255 area 0
Router(config-router)# exit

Context Managers

Use context managers for resource management.

Retry Mechanism

Implement retry logic for transient failures.

import time
from functools import wraps

def retry(max_attempts=3, delay=1):
    def decorator(func):
        @wraps(func)
        def wrapper(*args, **kwargs):
            attempts = 0
            while attempts < max_attempts:
                try:
                    return func(*args, **kwargs)
                except Exception as e:
                    attempts += 1
                    if attempts == max_attempts:
                        raise e
                    time.sleep(delay)
            return None
        return wrapper
    return decorator

@retry(max_attempts=3, delay=2)
def unreliable_operation():
    # Operation that might fail temporarily
    pass

ImagePullBackOff on EKS? Check these 5

Oct 2026 · 2 min read

  • kubectl describe pod— the Events section tells the truth. Check image name:tag typos first.
  • Private ECR? The node / IRSA role needs ecr:GetAuthorizationTokenand pull permissions.
  • Is imagePullSecretsset on the pod or service account?
  • Can the node reach the registry? No NAT / blocked egress = no pull.
  • Still stuck? Pull manually from a node to isolate registry vs cluster issue.

Why Terraform remote state is non-negotiable

Oct 2026 · 2 min read

  • Local terraform.tfstatebreaks the day a second person runs apply.
  • S3 backend+DynamoDB state locking = one source of truth,no clobbering.
  • State files hold secrets — encrypt at rest,lock down IAM,never commit to git.
  • Rule of thumb:if more than one human touches infra,state lives remote. Always.
